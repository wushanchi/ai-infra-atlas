MAINTENANCE GUIDE

维护与更新指南

本仓库是一套纯静态的 AI Infra 资源导航站，数据与展示分离，便于长期维护。所有资源集中在 data/resources.js 一个文件里，新增或修改资源无需改动任何 HTML/CSS。

项目结构

ai-infra-tutorial-deephy/
├── index.html          # 入口页：路线图 + 阶段概览 + 路径摘要
├── resources.html      # 资源库：筛选/搜索/进度/导出
├── paths.html          # 学习路径 + 实战项目 + 能力目标
├── about.html          # 本页：维护指南
├── data/
│   └── resources.js    # ★ 数据源（唯一需要维护的文件）
├── assets/
│   ├── style.css       # 共享样式（亮/暗双主题）
│   └── app.js          # 共享脚本（主题/导航/进度/筛选）
├── validate.py         # 数据校验脚本
└── README.md           # 项目说明
设计原则：数据与展示分离。所有页面通过 <script src="data/resources.js"> 加载数据，再由 assets/app.js 渲染。修改资源只需编辑 data/resources.js。

如何新增 / 编辑资源

打开 data/resources.js，在对应 stage 的 resources 数组里追加一个对象即可。下面是一个完整字段示例：

{
  "id": "my-resource",                 // 唯一标识，英文短横线，不可重复
  "title": "资源标题",
  "org": "作者 / 机构",
  "year": 2025,
  "stage": 4,                          // 1-7，对应学习阶段
  "focus": "推理引擎",                  // 专项方向
  "type": "开源项目",                   // 资源类型
  "platform": "GitHub",                // 平台
  "level": "进阶",                     // 入门 / 进阶 / 高级 / 入门→进阶
  "priority": "核心必修",               // 核心必修 | 强烈推荐 | 选修拓展
  "effort": "20–40 小时",              // 预计投入
  "format": "源码 + 文档",             // 形式
  "tags": ["CUDA", "Kernel"],          // 标签数组
  "desc": "一段客观描述，讲清楚是什么。",
  "why": "推荐理由：为什么值得学、在路线中起什么作用。",
  "url": "https://主链接",
  "secondary": "https://补充链接",      // 可选
  "secondaryLabel": "GitHub 仓库",     // 可选，补充链接的文字
  "access": "访问说明（可选）",         // 可选，如需特殊说明
  "maturity": "成熟度（可选）",         // 可选
  "order": 0                           // 阶段内排序，数字越小越靠前
}

字段速查

  • id：唯一，英文+短横线，用于进度标记与去重。
  • stage：1 全景基础 / 2 硬件并行 / 3 算子压缩 / 4 推理引擎 / 5 分布式通信 / 6 性能度量 / 7 生产部署。
  • priority：只能填「核心必修」「强烈推荐」「选修拓展」三者之一（影响颜色与排序权重）。
  • order：阶段内排序，建议从 0 开始递增。
  • url / secondary：主链接必填；补充链接（如 GitHub 仓库、论文、播放列表）选填。

校验数据

修改后建议运行校验脚本，检查必填字段、ID 唯一性与优先级取值：

python validate.py

脚本会输出每个缺失/异常字段，全部通过即数据完整。它还会同步生成 data/resources.json，方便其他工具读取。

本地预览

本站为纯静态站点，直接用浏览器打开 index.html 即可预览（数据通过 <script> 加载，兼容 file:// 协议，无需起服务器）。如需带热重载的开发体验，可在项目目录任选其一：

# 方式一：Python 内置服务器
python -m http.server 8000

# 方式二：Node 静态服务器
npx serve .

然后访问 http://localhost:8000。

部署到 GitHub Pages

  1. 在 GitHub 创建仓库（如 ai-infra-guide）并推送全部文件。
  2. 进入仓库 Settings → Pages，Source 选 Deploy from a branch，分支选 main、目录选 / (root)，保存。
  3. 稍候片刻即可通过 https://<用户名>.github.io/ai-infra-guide/ 访问。
  4. 后续更新只需推送代码，Pages 自动重新部署。

更新建议

  • AI Infra 演进快，建议每季度复查一次链接有效性（可用 validate.py --check-urls 联网校验，见脚本说明）。
  • 新增资源时务必填 why，说清它在学习路线中的定位，避免堆砌。
  • 同一主题若已有更优资源，考虑替换而非无限追加，保持地图精炼。
  • 优先级会随时间变化：曾是「核心必修」的工具若被取代，及时降级。

与参考项目的关系

本项目参考了 AIInfraGuide 的主题划分思路，但定位不同：AIInfraGuide 是原创中文教程站，本项目是资源导航与学习路线地图，聚合课程、源码、官方文档与视频，按七阶段知识依赖重组，帮助系统规划学习路径。两者互补：用本地图规划路线，用 AIInfraGuide 等教程深入学习具体主题。
